Common issues

Transfer stops when the screen locks

  • Open system Settings → Apps → Queora → Battery → set to Unrestricted.
  • Allow notifications so the ongoing download notice can stay visible.

Permission or “storage” errors

  • Settings inside Queora → Choose folder, and pick a location you can write to.
  • You do not need an SD card. App storage works without a custom folder.

Stuck near the end

  • The app merges parts after the last bytes arrive. Wait for status Merging parts… then Done.
  • If it fails, use Resume. Part progress is stored on the device.
